# Прежняя настройка DeepSeek review

Обязательный отдельный DeepSeek отменён. Текущий пайплайн использует ту же модель,
что генерация, отдельным запросом с новым контекстом:
[актуальная настройка](model-security-review.md).

`--security-config` и `security_backend` удалены из execution loop. Используйте
один `--adapter-config`. Прежний вспомогательный `deepseek_review.py` не вызывается
пайплайном; его тесты хранения credentials сохранены. Существующий файл ключа
автоматически не читается и не удаляется. Защита `deepseek.key` в .gitignore остаётся.
