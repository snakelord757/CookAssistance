Каноническая реализация — `feat/CA-LM-local-model` (`e280a6d`), включающая
`feat/CA-MVP` (`1e2a58f`). Она уже была слита на GitHub коммитом `1141bdf`.
Локальный main обновлён с сохранением текущих правок AGENTS/profiles,
ANDROID.md и TASKS.md.

Ранний прототип `feat/AND-001-cooking-assistant` и исправления
`fix/AND-001-BUG-1-navigation`, `fix/AND-001-BUG-2-ime` сохранены в истории
main. Это альтернативная реализация с другим API рецептов; она не заменяет
новый каталог, избранное, сервер и локальную модель. Деревья `afd3a1e` и
`3d7622f` идентичны, поэтому второй вариант исправления сохранён как история,
без дублирования кода.

Её пять регрессионных unit-тестов перенесены с адаптацией к String ID.

`ImeReachabilityTest` из старого worktree адаптирована к текущему repository
API; проверяются landscape, шрифт 200%, реальная клавиатура, положение кнопки
и фактическая отправка через физический touch. Старая проверка автоматического
mic permission prompt неприменима: текущий экран запрашивает его по кнопке.
Исходный worktree и его незакоммиченная правка сохранены.

Ветки LOOP-001/002 уже были предками main. Новая security-интеграция отменена
пользователем и в это объединение не входит.

Проверки и временные снимки записываются локально в `reports/INTEGRATE-001/`
и `workflow/tasks/INTEGRATE-001/`. Старые AI smoke-отчёты остаются историческими;
объединение не означает новый live-прогон DeepSeek или локальной модели.
